System Commander / Setup

Connect your computer.
Then let AI act.

The setup is simple: create a device registration in System Commander Cloud, run the generated command on your computer, and then connect your AI client.

3 steps Windows · macOS · Linux Remote MCP
Open System Commander Cloud ↗
01 / CLOUD

Create your device registration

Open System Commander Cloud, sign in, and create a fresh device registration. Cloud generates the device ID and authentication token for that computer.

Treat the token like a password. Keep the generated command private and use the command exactly as Cloud gives it to you.

02 / COMPUTER

Run the pairing command

Copy the command shown by Cloud and paste it into Terminal, PowerShell, or your preferred shell. The agent installs what it needs through npx and starts the local System Commander engine.

Generated by System Commander Cloud Do not edit
npx @leukode-labs/system-commander@latest remote --relay https://system-commander-cloud-production.up.railway.app --device-id YOUR_DEVICE_ID --token YOUR_DEVICE_TOKEN

Your real command will contain your own device ID and token. Do not replace them with the placeholders above.

03 / AI CLIENT

Connect your AI

Leave the remote agent running. Then use your AI client's MCP connection flow to connect to System Commander Cloud. Cloud and your AI client handle authentication; the connected computer remains the execution authority.

The exact MCP connection UI differs between clients and can change over time. Use the current connection details shown by System Commander Cloud rather than manually inventing an endpoint or token.

Give this to your AI

Let ChatGPT or Claude walk you through it.

Copy the prompt beside this card into the AI client you already use. It tells the AI to guide the setup without inventing credentials, modifying your device token, or sending you down a stale troubleshooting path.

Never paste an old device token from a previous setup attempt when Cloud has issued a new registration. Use the exact command generated by your current Cloud account.
Setup assistant prompt ChatGPT / Claude
DEVICE_NOT_REGISTERED Create a fresh device registration in Cloud. The old device record is gone; do not try to reuse its ID and token.
TOKEN_INVALID Generate a current registration and run the exact command Cloud gives you. Do not manually edit the token.
Cloud connection failed Check the relay URL and internet connection. Keep the relay URL exactly as provided by System Commander.
